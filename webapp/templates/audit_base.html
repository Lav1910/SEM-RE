How this audit works

  1. Buyer questions. We write {{ A.questions|length }} questions a home buyer in {{ A.market.city }} would ask, weighted by Google search demand.
  2. Five AI platforms. Each question is asked live on ChatGPT, Gemini, Perplexity, Google AI Overviews and AI Mode, set to the builder's market.
  3. Who gets named. We record which builders each answer names and which websites it cites.
  4. The score. AI Visibility is the share of non-brand answers that name the builder, weighted by demand. Brand-name questions don't count.
  5. History. Google AI Overview history comes from Semrush. HBM points are added each time the builder is audited.

Website checks (markup, crawlers, reviews) are read from the site itself, not from AI answers.
