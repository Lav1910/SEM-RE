Connect an AI agent

Let Claude, ChatGPT, Grok and other AI agents use AEO Snapshot as you: look up audits, run new ones, make client links and check who opened them.

Connector address (MCP server URL)
{% for k, lab in (('claude', 'Claude'), ('chatgpt', 'ChatGPT'), ('grok', 'Grok'), ('code', 'Claude Code · Cursor')) %} {% endfor %}
  1. In Claude (web or desktop), open Settings › Connectors and choose Add custom connector.
  2. Name it AEO Snapshot and paste the address above. Click Add.
  3. Click Connect, sign in here and click Allow. Then ask Claude things like “run a Quick audit on builder.com”.

On a Claude Team or Enterprise plan, an owner adds the connector once for the organization first.

  1. In ChatGPT, open Settings › Apps & Connectors › Advanced settings and turn on Developer mode.
  2. Back in Apps & Connectors, choose Create. Name it AEO Snapshot, paste the address above and pick OAuth for authentication.
  3. Sign in here and click Allow. In a chat, turn on AEO Snapshot from the tools menu.

Developer mode is available on paid ChatGPT plans.

  1. Create an access token below.
  2. In xAI's API (Grok), add a remote MCP tool with the address above as the server URL and the token as the authorization: Bearer aeo_pat_…
  3. Ask Grok to use the AEO Snapshot tools.

If your Grok app offers custom connectors, add the address above there and sign in when asked.
